# Puzzle Arcade

Sudoku, Number Match, Wordle and Mastermind in one installable phone web app, with an Elo rating for each game. Puzzles get harder as your rating climbs.

- Works offline and saves ratings on the phone.
- Optional accounts (username and password) sync ratings across devices through a small Supabase database.

Run it locally with `python3 -m http.server 8000` and open http://localhost:8000.

Deploy and account setup: see [SETUP.md](SETUP.md). Notes for working on the code: see [CLAUDE.md](CLAUDE.md).
